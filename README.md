## What is Nexify?

Nexify is a lightweight Windows scanner built for staff and organizations that need to quickly check machines for suspicious activity.

Staff generate a temporary PIN from the web panel. The user runs a small scanner, enters the PIN, and the results appear on the dashboard in real time. No installation, no complicated setup.

**[Open Dashboard](https://forensic.nexifysystems.xyz)** · **[Join Discord](https://discord.gg/WUrRjx4pBE)**

---

## What it checks

- Recent program execution history
- Signs of process manipulation
- Deleted files and cleaner traces

Results are automatically categorized as **Clean**, **Suspect**, or **Flagged**.

---

## Cloud Panel

Everything is reviewed from the browser.

- Enter the session PIN to open the report
- Full history of previous scans
- Staff activity logs

Works on both desktop and mobile.

## How it works

1. Staff opens the dashboard and creates an 8-digit PIN
2. User downloads and runs `Nexify-Scanner.exe` as Administrator
3. User enters the PIN
4. Scan finishes in under a minute and uploads the results
5. Staff sees the full report instantly
